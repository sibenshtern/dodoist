# ADR-008: Библиотека для построения графиков

**Статус:** Принято

---

## Контекст

Аналитический раздел продукта требует визуализации данных: burndown-диаграмма (линейный график с идеальным и фактическим сгоранием задач), velocity по спринтам (столбчатая диаграмма), метрики по участникам. Нужна библиотека, совместимая с Angular и не требующая значительных усилий на кастомизацию.

Рассматривались варианты:

| Библиотека | Примечание |
|---|---|
| ApexCharts (`ng-apexcharts`) | Готовые Angular-компоненты, богатый набор типов графиков |
| Chart.js (`ng2-charts`) | Популярная, но требует ручной адаптации под Angular |
| D3.js | Максимальная гибкость, высокий порог входа |
| ECharts (`ngx-echarts`) | Мощная, но увесистая библиотека от Apache |

---

## Решение

Мы будем использовать **ApexCharts** через официальную обёртку `ng-apexcharts`. Библиотека предоставляет Angular-компоненты с типизированным API, поддерживает все необходимые типы графиков (area, bar, line) и не требует ручного управления жизненным циклом Canvas.

---

## Последствия

**Положительные:**
- Нативная Angular-интеграция — не нужны ручные обёртки или `ngOnChanges`-хаки
- Готовые темы и адаптивность без дополнительных усилий
- Активно поддерживается, хорошая документация с примерами

**Отрицательные:**
- Увеличивает размер бандла (~200 кБ gzip)
- Менее гибкая, чем D3.js, при нестандартных требованиях к визуализации
- Внешняя зависимость: изменения в API библиотеки могут потребовать адаптации
